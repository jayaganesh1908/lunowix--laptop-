# Lunowix - Compare Laptops, Phones & Headphones

Lunowix is a device comparison platform that helps users discover and compare laptops, phones, and headphones.

## Features

- Compare products side by side
- Browse laptops, phones, and headphones
- User authentication
- Save products to wishlist
- Search and explore products
- View detailed product specifications

## Tech Stack

- Next.js
- React
- TypeScript
- Supabase
- Tailwind CSS
